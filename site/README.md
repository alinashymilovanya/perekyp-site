# iPhone Monitor — web-кабинет

Отдельный локальный сайт поверх существующего бота. Он не меняет файлы бота и не записывает данные: читает `data/runtime-status.json` и историю уведомлений из `data/seen.sqlite3` в режиме только для чтения.

## Запуск

Из этой папки:

```powershell
uv run --no-project python server.py
```

Откройте <http://127.0.0.1:8765/>.

## Что доступно

- обзор состояния процесса и хранилища;
- история сохранённых уведомлений с поиском и сортировкой;
- калькулятор потенциальной маржи по формуле бота;
- адаптивный интерфейс для телефона и компьютера.

Сейчас сайт показывает только данные, которые бот уже сохраняет. Управление `/pause` и `/resume` намеренно не имитируется: в текущем боте эти команды ещё не подключены к реальному источнику.

## Проверка

```powershell
node --test tests/app.test.js
uv run --no-project python -m unittest discover -s tests -t site -v
```
