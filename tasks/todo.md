# Задачи: круглосуточный режим

## Фаза 1 — источник данных

- [ ] Выбрать и проверить разрешённый источник новых публичных объявлений.
- [ ] Подключить источник к текущему парсеру и покрыть интеграцию тестом.

## Фаза 2 — запуск 24/7

- [ ] Подготовить Linux VPS и секреты в `.env`.
- [ ] Добавить Docker/systemd-автоперезапуск и health-check.
- [ ] Настроить ежедневный backup базы.

## Фаза 3 — наблюдаемость

- [ ] Добавить адаптивную паузу при ошибках источника.
- [ ] Добавить Telegram-предупреждение о недоступности источника.
- [ ] Настроить ежедневную сводку по времени Астрахани.

## Контрольная точка

- [ ] Бот переживает перезапуск VPS и временную сетевую ошибку.
- [ ] Новая запись приходит в Telegram не более одного раза.
- [ ] Токен и база не попадают в Git.
