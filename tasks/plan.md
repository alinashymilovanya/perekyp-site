# План: круглосуточный монитор iPhone-объявлений

## Цель

Бот постоянно получает объявления из разрешённого источника, отбирает новые записи, оценивает цену и присылает их в Telegram. После перезагрузки сервера или временной ошибки он запускается сам.

## Архитектура

```text
Разрешённый источник объявлений
            ↓
Монитор на VPS (24/7, перезапуск при сбоях)
            ↓
SQLite + ежедневная резервная копия
            ↓
Анализ цены, состояния и рисков
            ↓
Telegram: мгновенные карточки + ежедневная сводка
```

## Решения

- Запускать на небольшом Linux VPS, а не на домашнем компьютере.
- Использовать официальный API или лицензированный источник данных; не обходить CAPTCHA, IP-блокировки и ограничения сайта.
- Использовать SQLite для одного пользователя и ежедневный backup базы.
- Хранить токен Telegram только в `.env` на VPS.
- Запускать процесс через systemd/Docker с автоматическим перезапуском.
- При сбоях источника делать паузу с постепенным увеличением интервала, а не повторять запросы бесконечно.

## Критерии готовности

- После перезагрузки VPS бот автоматически возвращается в работу.
- Невалидный ответ или временная ошибка источника не останавливают бота.
- Новое объявление приходит один раз; повторные не дублируются.
- Если источник недоступен дольше заданного времени, в Telegram приходит техническое предупреждение.
- Ежедневная сводка отправляется в заданное время по Астрахани.

## Риски

| Риск | Как снижаем |
|---|---|
| Нет разрешённого доступа к публичной выдаче | Не обещаем 24/7 до выбора официального или лицензированного источника. |
| Временный сбой VPS или Telegram | Автоперезапуск, повторные попытки и health-check. |
| Ошибка оценки цены | Показываем оценку как ориентир и сохраняем факторы расчёта. |
| Потеря истории | Ежедневная резервная копия SQLite. |
