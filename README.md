# iPhone Monitor

Основа бота для мониторинга объявлений iPhone и уведомлений в Telegram.

## Безопасность

- Реальный токен Telegram хранится только в `.env`.
- Файл `.env` исключён из Git.
- Не отправляйте токены в чат, issues или коммиты.

## Запуск Telegram-части

После заполнения `.env` запустите из корня проекта:

```powershell
$env:PYTHONPATH = "src"
python -m iphone_monitor.main
```

Затем откройте бота в Telegram и отправьте `/start`.

## Текущий срез

В проекте есть проверяемый расчёт потенциальной маржи:

`рыночная цена - цена объявления - доставка - комиссия - резерв ремонта`

Источник объявлений Авито подключается отдельным адаптером после проверки доступного и разрешённого способа получения публичных объявлений.

Сейчас Telegram-часть принимает `/start`, `/status`, `/pause`, `/resume` и неизвестные команды, а также умеет отправлять форматированные карточки объявлений.
